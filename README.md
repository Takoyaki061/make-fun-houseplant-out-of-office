Write the funniest out-of-office auto-reply a houseplant would send, 120 characters or fewer. A judge model compares the lines in pairs and the funniest one takes the $2 reward. Free to enter.

The entry: "This is an automatic reply. I am a plant. I cannot read email. I have been dying quietly by the printer since February." (119 characters — see CANDIDATES.md for the 8 candidates and the critique-pick.)

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (or `$OUTPUT_PATH`). Standard library only, deterministic.
